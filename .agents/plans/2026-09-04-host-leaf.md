# Host-as-a-leaf implementation plan

Status: **done** (2026-09-04). Spec: `.agents/specs/host-leaf.md`
(normative; this plan only sequences it). Ships as the next patch with
the playground editor fill, the empty-host path, and the slot hide
already staged; `focus="arrows"` follows in its own patch.

## Phases (each ends green: `pnpm check` + the visual sweep)

### 1. Tree builder — the leaf branch as a function

- `buildLeaf(root, style, nodes, ctx)` in tree.ts: the current leaf
  branch (run extraction, intrinsic sizes, form-control sizing, box and
  out-of-flow children, source runs) over an explicit node list;
  `collectRun` takes the node list too. `buildTree`'s leaf case calls
  it with `root.childNodes`.
- `buildRootLeaf(host, style, ctx)`: `buildLeaf` over the host's child
  nodes minus `[data-mw-probe]`, exported for element.ts.
- `rootLeafStyle(host)`: `defaultCellStyle()` with the text properties
  of `readCellStyle(host)` copied over — whiteSpace, tabSize,
  textIndent, textAlign, textAlignBlocked, textOverflow, overflow,
  textDecorationLine — tracking and lineGap left at zero.
- Node tests (`tree.test.ts` or a new `host-leaf.test.ts`, happy-dom):
  the spec's list — text, an inline element with padding cells, an
  atomic box marker, an out-of-flow child, the probe excluded, a
  `<br>`; a host with a block child stays a container with
  `droppedText`.

### 2. Element, renderer, companion CSS

- `#performLayout`: after the role scan, when no element child is a
  block and the host has inline content (`hasDirectText` or an inline
  child), `virtualRoot = buildRootLeaf(...)`; otherwise the existing
  container root. `data-mw-dropped-text` and its warning only on the
  container path.
- render.ts `walk(root, true)`: for a root with text, write the host
  flags (`data-mw-leaf`, `data-mw-nowrap`, `data-mw-pre`, `--mw-ti`,
  `data-mw-text-align-blocked`); clear them on a container root.
- styles.css: host variants of the fill/decoration lock, the
  `::selection` invert, `[data-mw-nowrap]`, `[data-mw-pre]` (and its
  ` *`), the text-indent rule, `[data-mw-text-align-blocked]`. Shadow
  sheet: `#grid { -webkit-text-fill-color: currentColor }`.
- `#unitAt`: when the stack yields no text leaf, try
  `this.#lastLayout` itself (`isTextLeaf`, `charIndexAtCell` at 0,0);
  the root's paragraph unit is `positionOf(0)` through the run's last
  mapped position, boxes included.
- Story `Test / Host` extended per the spec (all three engines via the
  vitest browser projects).

### 3. Visual, docs, release

- `visual/selection.spec.ts`: a `test-selection--host-text` fixture
  (a text-only host, `max-w-64`), both modes, three engines — six new
  goldens generated in Docker and eyeballed.
- README: one sentence in "Selection" (or the intro) that the host's
  own text renders like any element's.
- cell-model.md, semantic-selection.md touch points per the spec; spec
  status → implemented; the deferred section stays.
- Version: bumped when the next patch ships (more work is queued for
  it); its release notes cover the iOS touch-selection fix and
  full-width rows (already on main), the playground editor fill, the
  empty-host fix, and the host as a leaf.

## Risks

- **Fill inheritance into nested shadow leaves** (`<mono-ascii>`'s
  transcript): already transparent through the descendant lock;
  unchanged.
- **A host with only whitespace text and no children**: `hasDirectText`
  is false → the empty root, as today.
- **`text-indent` on the host**: authored px would drift the native
  copy; the host variant of the text-indent rule rewrites it in cells,
  as on leaves (probed).
